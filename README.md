# Tools for Xero

A browser extension for the Xero accounting web app that provides a configurable dark mode, flyout menus and other ui improvements.

## What it does

- Provides configurable Dark Reader styling, following system, dark, or light mode
- Toggles a sticky top navigation bar
- Adds custom flyout menus to existing nav items
- Inserts menu items into existing Xero menus
- Saves theme settings and on/off state through browser storage

## Is it safe?

Yes, the extension only modifies the appearance and behavior of the Xero web app in your browser. 
It does not collect or transmit your data to external servers. All settings are stored locally in your browser's extension storage.
It only uses only the permissions necessary to modify the Xero web app's appearance and behavior, and does not request access to your personal data or other websites.

## Supported browsers

- Firefox
- Chrome
